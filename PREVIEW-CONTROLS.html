5. Dropdowns and tick boxes

The closed box is themed and the arrow is drawn. The list it opens is Chrome's and cannot be styled — that is a limitation of the browser, not a loose end.

6. Pick lists — before and after

Both sides hold the same options. The left is what Administration and the Resource Directory show today; the right is the same control after enhancement.

Before — native multiple-select

Selection is highlight only, which is also what hover looks like. Adding a second item needs Ctrl held down, and clicking without it clears everything already chosen.

After — tick boxes, same control underneath

Tick, plum text and plum tint all say the same thing. Click anywhere on a row. The count is stated, and Clear cannot happen by accident.

7. The part that matters — the page still reads the same control

The tick boxes write straight back into the hidden select. This reads it exactly the way resource-directory-page.js does, on every change. If these two ever disagree, the enhancement is broken.

Nothing here is live. The application does not load either file yet, and the file list the public repository receives is derived by following what each page asks for — so neither can reach your testers until we link them, which is a one-line change per page once UAT closes.
