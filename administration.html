Data and backup

Everything in this tool is held in this browser. Clearing browsing data, a rebuilt laptop or a new machine takes it all with it, and there is no copy on a server. Download a backup regularly and keep it somewhere the organisation backs up, such as OneDrive or a team SharePoint folder.

Storage in use

Browsers allow roughly 5 MB. Once that is full nothing more can be saved, so keep an eye on this figure and archive the audit history when it grows.

Download a backup

Produces a single file containing every project, plan, milestone, RAID item, register, benefit, financial record, stage gate, configuration setting and audit event. Personal items such as your sign-in session are not included.

The file contains no passwords — sign-in is handled by Supabase Auth — but it does include people, roles and portfolio data, so store it as confidentially as the tool itself.

Archive audit history

Audit history grows with every saved edit and is usually the largest thing stored. Archiving downloads the older events as their own file and then removes them from the browser, freeing space. Nothing is removed until the file has been produced.

Restore from a backup

Replaces everything currently in this browser with the contents of a backup file. Use it to move the portfolio to a new machine, or to recover after data has been lost.

This cannot be undone. Download a backup of what is here now before restoring.
