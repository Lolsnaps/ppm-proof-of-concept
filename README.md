# Foresters Portfolio

An internal portfolio and project management tool, running as a private pilot.

This repository exists only to host the application. It is not documentation, and no reuse is
intended or licensed.

## For people testing it

You need an account before the tool will show you anything; there is no self-registration. Ask
Alex to set you up. You will be given an email address and a temporary password, and on first
sign-in the tool takes you through setting up an authenticator app and choosing your own
password.

Both the password and the 6-digit code are required every time. The second step cannot be
skipped.

## Reporting something

Send Alex a note, or open an issue here. What helps most:

1. What you were trying to do
2. What happened instead
3. The page you were on
4. Anything red in the browser console - press `F12`, click **Console**, and copy what is there

That last one is worth more than everything else combined.
